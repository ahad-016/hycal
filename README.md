## 🚀 How to Run Locally

### Option 1: Built-in Zero-Dependency Server (Instant)
Run the lightweight built-in HTTP server:
```bash
node server.js
```
Then open `http://localhost:3000` in any web browser.

### Option 2: Direct Browser Execution
Double-click `index.html` or open it with Chrome, Edge, Safari, or Firefox directly.

### Option 3: Modern Vite Dev Server (If Node/NPM installed)
```bash
npm install
npm run dev
```

## 📝 How to Customize Content & Placeholders

All business data is separated from UI logic inside `src/data/`:

1. **Company Contacts:** Edit `src/data/company.js` to change phone numbers, email addresses, or Google Maps links.
2. **Project Case Studies:** Replace placeholder entries in `src/data/projects.js` with actual client project names, photography, and confirmed tonnages once non-disclosure clearances are approved.
3. **Customer Testimonials:** Update `src/data/testimonials.js` with real Google Reviews or client feedback letters.
4. **HVAC Systems:** Update confirmation statuses in `src/data/systems.js` to match specific workshop capabilities.
5. **Services & Scope:** Modify or add specific deliverables in `src/data/services.js`.
